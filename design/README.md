# Design / UI 原型

正式视觉：

> Neumorphism · 雾霾蓝 / 靛青 / 青绿

打开：

`all2api-ui-neumorphism-blue.html`

这是当前的可交互单文件原型，展示：

- Header
- Sidebar
- 运行总览
- KPI
- 请求趋势
- 渠道健康
- 账号池
- 路由规则
- 最近请求
- Light / Dark

该文件主要用于视觉与交互方向确认，不代表完整后端已经实现。

## 本次统一项目交互约束

- 账号新增的第一步必须是渠道选择；选择后才读取该渠道的 flow schema，展示二维码、OAuth 或 token 导入字段。
- 渠道选项、能力标签和账号流程来自后端 registry/manifest，不在原型或页面代码中硬编码平台分支。
- 网关密钥创建/编辑必须展示渠道范围和模型范围；空渠道范围代表全部当前已启用渠道，最终授权由服务端校验。
- 原型中的三渠道名称用于验证信息架构，不代表运行时连接三个外部反代项目；目标态由 All2API 内置 adapter/worker 提供能力。
