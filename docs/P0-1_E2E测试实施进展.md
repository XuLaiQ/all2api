## 真实账号来源

- ChatGPT：仓库根目录 `sub2api-export-1790396257763.json`，读取根 `accounts[]` 中的嵌套 `credentials`。文件只作为本地 E2E 输入，不在启动时自动导入。
- WorkBuddy：`F:\token-p\WorkBuddy\wb2api\data\auths\workbuddy*.json`。测试读取嵌套 `auth/account`，不会修改源文件。
- Doubao：`F:\token-p\反代\doubao2api\data\accounts\<account_id>\browser`。测试复制到临时目录后启动 Chromium，源 profile 不会被打开或写回。

启用源账号读取需要显式设置 `E2E_USE_SOURCE_ACCOUNTS=true`，并按 `services/api/.env.e2e.example` 配置路径。凭据只在进程内流转到 adapter/CredentialStore。

## 已完成实现

### ChatGPT Web

- `ChatGPTWebClient` 使用 ChatGPT Web 的 `/backend-api/me`、`/backend-api/models`、sentinel requirements 和 `/backend-api/conversation`。
- ChatGPT Web SSE 被转换为 OpenAI-compatible 非流式/SSE 响应。
- 请求包含稳定的设备/会话头和 target path/route；认证、限流、超时、协议错误均映射为安全错误。
- ChatGPT runtime 已接入 registry，统一 gateway 不再把 OAuth token 当作 `api.openai.com/v1` API Key。

真实阻塞证据：

```text
ChatGPT /backend-api/models -> httpx.ConnectError: All connection attempts failed
```

这代表当前网络环境不可达，不代表 E2E 通过，也不应改为 skip 掩盖。

### WorkBuddy

- `WorkBuddyProvisioner` 支持管理员主动 token import，写入本地加密 CredentialStore 和账号快照。
- client 使用真实协议：`/v2/plugin/auth/*`、`/v3/config`、CN 企业模型目录、Global 企业模型目录和 `/v2/chat/completions`。
- realm、Origin/Referer、CLI UA、`X-User-Id`、`X-Domain`、`X-Enterprise-Id`、`X-Tenant-Id`、`X-Device-Token` 等头由 client 统一生成。
- 真实 Global 账号模型目录调用已通过；测试只输出状态和模型结构摘要。

### Doubao

- Playwright worker 支持 persistent profile，但 E2E 只使用源 profile 的临时副本。
- worker 会话中只检查登录 selector 或 cookie 名称是否存在，不读取或返回 cookie 值。
- worker 支持启动、导航、会话快照、取消、重启恢复；24 小时稳定性测试继续显式 opt-in。
- 真实 Chromium 启动和导航已通过；当前 profile 的登录态检查失败，保留为真实失败。

## 验证命令

在 `services/api` 目录执行：

```powershell
uv run --extra dev python -m pytest -q --disable-warnings
```

当前结果：`115 passed, 20 skipped`。跳过项仅包括显式关闭的真实平台 E2E/长时测试。

真实 WorkBuddy 验证示例：

```powershell
$env:E2E_ENABLED='true'
$env:E2E_WORKBUDDY_ENABLED='true'
$env:E2E_USE_SOURCE_ACCOUNTS='true'
$env:WB_TEST_AUTH_DIR='F:\token-p\WorkBuddy\wb2api\data\auths'
uv run --extra dev python -m pytest tests/e2e/test_workbuddy_e2e.py -q -k 'token_validation or adapter_import_account or adapter_list_models'
```
